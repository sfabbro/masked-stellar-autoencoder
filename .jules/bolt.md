## 2024-05-20 - PyTorch Masked Reduction Optimization
**Learning:** In PyTorch, using dynamic-shape boolean array indexing (e.g., `input[mask]`) prior to reduction operations (like `.mean()` or `.sum()`) triggers costly CPU-GPU synchronizations to determine the resulting tensor's dynamic shape, creating a significant performance bottleneck during loss calculations.
**Action:** When implementing custom PyTorch loss functions with reductions, replace boolean indexing with full-shape tensor operations and `.masked_fill_(~mask, 0.0)` followed by a clamped sum reduction (e.g., `.sum() / mask.sum().clamp(min=1)`). Maintain standard boolean indexing exclusively for the `reduction='none'` API fallback.
