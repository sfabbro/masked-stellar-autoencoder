# Supervised XP augmentation and independent-seed ensemble

This is a proposed bounded arm list, not an accepted CANFAR run. Each arm uses the existing epoch72 parent, native19859strict fits/100620measurement-test stars and the fixed10M reconstruction presentations (9MTRAIN+1Mrepeat). The parent supplies the same trained representation; independent experiment seeds vary head initialization, dropout, label draws and reconstruction masks. Augmentation policy controls at a given experiment seed retain matched label/reconstruction-mask streams; all arms retain row ordering, budgets, feature allowlist and target scales. Independent seed replicas must not falsely assert equal label/mask hashes across seeds. The schema is in configs/augmentation-ensemble-10m.yaml; the main launcher integration is separate.

The first comparison contains residual-Huber controls at experiment seeds42/43/44, half-sigma per-star XP Gaussian noise, coefficient masking10%, one-BP-or-RP-band masking on20% of rows, and combined half-sigma+band masking. The two mask policies hide11coefficients per star in expectation when all110are observed; realized hidden counts are recorded, not asserted identical. The encoder has no appended missing-mask channels: its MaskedPeriodicEmbeddings recognizes the parent's -9999sentinel. All perturbations are applied to supervised input clones, using actual visible masks; withheld/missing values are never restored. Reconstruction inputs, targets, validation inputs and labels are not augmented by this helper.

Noise uses the already audited per-star reported XP standard deviations divided by the observed-G normalization and parent scale, in exactly the same canonical BP1..55,RP1..55 order as the augmented columns. Half-sigma augmentation adds0.25times the quoted conditional variance. It is a robustness/regularization experiment, not EIV correction; extra noise may worsen dilution bias. Native off-diagonal XP correlations and common-G uncertainty remain omitted. No photometric zero-point/extinction/stellar-parameter perturbation is fabricated, and no fake physical error floor is introduced.

A named augmentation generator consumes a fixed draw layout for every policy, including zero-policy controls. It is independent of labels, reconstruction masks and globally reset dropout generators. The same source-row sequence can therefore share augmentation random numbers without modifying the established reconstruction/mask or label streams. Both500headwarmup and306adaptation updates use the same declared augmentation policy. Primary evaluation is always on the original unaugmented paired inputs. Source/raw-error audit must precede any noise fit; actual GPU input/mask/noise hashes and RNG states should be preserved. CPU output replay verifies the final model, not falsely claims independent reproduction of CUDA random masks.

The three independent control models form an arithmetic mean of paired dex predictions after each member independently passes CPU verification. Source IDs and row order must match exactly with integer precision; aggregation is float64. Report each member, three-member point mean and raw member spread. Spread is not calibrated predictive or frequentist uncertainty. The ensemble costs30Mtotal reconstruction presentations and three head warmups; compare it with a single10Mmodel with that compute difference explicit. A later augmentation ensemble needs additional independent seeds for that selected policy, not silently pooling different methods and calling them seed replicates.
