# Label-free test-time screen

The screen uses the actual independently verified residual-Huber winner (SHA558a317ec8d2101d9caae7fe4a29db5a67ba6124dac27daaaf3ce14b624453ac), its unchanged native-fit target scaling and original input allowlist, and the audited fixed10M source cohort. This is inference-only work: ZERO reconstruction training-row presentations. Do not advertise it as another10M replay/adaptation run.

The source cohort is unchanged. All100620native-test stars get a clean baseline and three8-view averages (one clean + seven augmented): XP masking probability.1, reported-error noise scale1, and their combination. Augmentation touches only genuinely observed110XP coefficients, never labels or reported errors. Missing/withheld entries retain -9999. Per-source/per-view deterministic random streams make object order irrelevant; independent masking/noise streams make the mask common to combined/mask-only variants. Observed G normalization/commonG and native off-diagonalXP covariance limitations remain as in the previous audited input-correction runs. Adding measurement noise doubles part of the input variance; averaging is an empirical robustness probe, not an asserted posterior estimator or EIV correction.

More expensive adaptation uses512test IDs selected by a fixed source-ID hash, with no target-conditioned selection. This subset may contain too few metal-poor stars for a useful tail claim. A separate256-object role1/benchmarkTRAIN tuning subset is selected by the same label-blind rule; role1 IDs are never fit/test stars of the base residual head. This is a reserved tuning role within the audited cohort, not certification that nobody ever inspected these stars in any historical experiment. All methods are predeclared and reported; test scores never choose learning rates, stopping, scopes or sample selection.

Four subset variants share one fixed per-object20%XP holdout: masked-view-only control; latent reconstruction refinement; encoder-LayerNorm-affine-only reconstruction adaptation; and the same LayerNorm adaptation plus frozen-head prediction consistency. At least one observedXP target is hidden and at least one remains visible. Reconstruction loss is computed ONLY on the held-out observedXP coefficients, which are actually replaced by -9999 before encoding. Latent refinement starts from the MASKED input's latent, not the clean latent containing its hidden targets. Compare latent refinement with its masked-view control as well as the clean baseline.

Latent refinement uses3Adam steps at.01 with.1latent anchor. The decoder and prediction head are frozen, and the global encoder is never updated. LayerNorm variants use3Adam steps at1e-4, only encoder LayerNorm affine terms trainable; decoder, other encoder weights and prediction head are frozen. A.1parameter-drift anchor is included; the consistency arm adds.1squared deviation from that object's clean baseline prediction. Clean baseline is a teacher anchor, not an observed test target. Neither input-label nor label-error values enter optimization. Stopping is the fixed3steps.

Each object restores selected parameter values, original requires_grad flags, gradients and module train/eval modes in a finally block. Optimizer state is new per object. Dropout is disabled. There is no batch adaptation or cross-star state. The complete original model/head tensor hashes and all100620clean predictions must be exactly unchanged after the screen. The first object's adaptation is repeated exactly as a runtime reset/reproducibility guard. Zero steps is the clean-baseline identity. Original rawsource/error/128XP audits gate production before inference, including the newly used tuning source rows.

Persist full test inputs/visible masks/scaledXP errors/measurements, selected test indices, role1 tuning source rows/inputs, all predictions, per-object adaptation diagnostics, exact hashes and the untouched checkpoint reference. Runtime strict winner-baseline tolerance is rtol=atol5e-5; before/after clean-baseline preservation is exact. Further independent CPU regeneration of augmentation streams and adaptation/reconstruction outputs, paired source/cohort checks and conditional/report/PNG/PDF visual QA are required before scientific claims. Huber variance channels and view spread are not calibrated uncertainty; per-object optimization does not imply a frequentist confidence or physical posterior.

Local smoke uses the actual winner/cohort, 128 test rows and 4+4 adaptation/tune stars; it deliberately skips the original mounted-source audits. It certifies numerical integration, state reset and serialization paths, not scientific performance, GPU throughput or original-source certification. The production GPU budget includes three variants with eight forward views each for 100620 stars, clean baseline checks, and 768 objects × nine optimization steps. It is not a matched training-compute comparison.
