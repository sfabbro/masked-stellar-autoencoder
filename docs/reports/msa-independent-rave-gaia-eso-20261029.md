# Independent RAVE and Gaia-ESO source status — 29 October 2026

## RAVE DR6

Use MADERA spectroscopic atmospheric parameters and GAUGUIN abundances computed with MADERA inputs. Do not use the Gaia-informed BDASP, GAUGUIN/BDASP or CNN as independent spectroscopy. MADERA's uncalibrated and calibrated values are both preserved; calibration can use external reference information, and GAUGUIN shares MADERA inputs and the same spectra, so these are dependent measurements, not independent repeated stars. MADERA [M/H] is not Fe/H. GAUGUIN reports its native Fe/H and alpha/Fe; no arbitrary conversion or pooling is made. References: [RAVE release](https://www.rave-survey.org/metadata/ravedr6/), [GAUGUIN/MADERA schema](https://www.rave-survey.org/metadata/ravedr6/dr6_gauguin_madera/), [CDS III/283](https://vizier.cfa.harvard.edu/vizier/ftp/cats/III/283/).

The raw MADERA table (518,387 observations) was joined by `rave_obs_id` to the published Gaia EDR3 table, yielding 517,357 candidate observations and 450,978 distinct Gaia identities before any training or feature cuts. GAUGUIN has 453,490 observations and 453,035 with candidate IDs, 398,885 distinct Gaia identities. Of those candidate observations, 328,018 have finite Fe/H and 429,731 finite alpha/Fe. These counts are observations, not disjoint stars, and no quality or range filtering has been applied. Measurements may include implausible values; quoted errors and fit diagnostics remain available for later filtering.

The published EDR3 crossmatch gives only the best neighbour, not all alternatives; a unique observation-key join is not independent proof of a unique physical match. Gaia EDR3 and DR3 share the source-identity system, but this does not validate the association. The raw RAVE source and resulting products are not yet joined to features, assigned training/test roles, or consumed by a trainer. The original GAUGUIN gzip, CDS ReadMe, both HDF5 source projections and receipts were preserved in `/arc/projects/k-pop/msa_runs/stellar-improvement-20261015/rave_dr6_cnn_recovery_sources_20261028_v1/`, private ACL and full remote SHA readback checked. The folder name is historical; the new files contain MADERA/GAUGUIN, not CNN. The first 100 parsed Fe/H and alpha values independently match Astropy's CDS ReadMe parser, including missing values.

## Gaia-ESO DR5.1

The staged final-release FITS file has 114,916 rows and 350 columns; all native columns, FITS units, formats, null markers and row IDs are preserved in the raw projection. Finite source values before quality/sentinel/identity filtering: Teff 97,499, logg 89,799, Fe/H 94,247, Mg I 54,223, Si I 34,556, Ca I 49,355, Ti I 39,147. These are not training-ready counts, and elemental columns are not combined into a fabricated alpha measurement. The source projection, receipt and release description are privately preserved under `/arc/projects/k-pop/msa_runs/stellar-improvement-20261015/rave_dr6_cnn_recovery_sources_20261028_v1/gaia_eso_dr51_raw_source_20261029_v1/` with remote SHA readback. The original input remains `/arc/projects/k-pop/catalogues/ges_dr5.1.fits`.

The actual 350-column file contains no Gaia ID, proper motion or coordinate epoch. The [release description](https://www.eso.org/sci/publications/announcements/sciann17584.html) describes different source astrometry for field and cluster targets; the staged release PDF identifies VISTA for field stars and 2MASS astrometry for clusters. Equinox J2000 does not establish the position's observation epoch. A proper-motion-aware DR3 xmatcher run is **not yet completed**: per-row astrometric provenance/epoch and Gaia candidate data must be recovered or modeled with explicitly documented assumptions; ambiguous and unmatched candidates must remain visible. Never silently declare all positions epoch 2000 or report best-neighbour-only results as certified. A published 2-arcsec Gaia-ESO/Gaia comparison is useful context, but is not evidence that our own requested proper-motion-aware crossmatch has run.

The local xmatcher checkout at `804b38b4221a20bc9610c8ab18b7167309bce3d5` was exercised with a synthetic star at epoch 2000 and a Gaia position displaced 2 arcsec at epoch 2016 with 125 mas/yr motion. At 0.5 arcsec radius it returned zero unpropagated matches and one match after propagation (separation about 3.1e-8 arcsec). This is a toy check of motion handling, not a crossmatch of Gaia-ESO.

## LAMOST DR12 status

The separately authorized LRS and MRS direct-route source recoveries completed, preserving the original raw FITS and source tables on CANFAR. LRS contains 8,376,135 spectra, 5,829,702 unique valid Gaia IDs and 3,334,358 rows matched to the existing 150M cache. MRS contains 3,224,901 spectra, 1,499,584 unique valid Gaia IDs and 889,924 rows matched to the cache. Cache counts are rows rather than independent stars, and LRS/MRS overlap; do not add them as unique stars. Outside-base ancestry remains unknown. These results have not been integrated into training, and producer output hashes have not been independently streamed in this step.
