# Corrected XP uncertainty experiments

Three matched epoch-27 continuations use the verified 9M train/1M validation benchmark, 20M presentations, seed42, optimizer batch32768 and microbatch512. AdamW moments and scaler are inherited; resumed LR is held fixed. All experiments retain whole-XP masking for50% of stars and independent20% masking for other inputs. Identical row and mask generators and dropout microbatches support matched comparisons. Compare only completed experiments with equal parent checkpoint hash, benchmark source-ID hash, validation ID, masks, presentations and optimizer steps. The earlier prefix-sampled control is not the matched control for this benchmark.

Stored coefficients are already normalized to G=8.5. Raw XP error columns are corrected by dividing by `f=10**((8.5-G)/2.5)`, then by the matching reference scaler scale. Magnitudes are only RobustScaled. Original HDF5 fields are never rewritten. Missing/invalid errors retain the existing fixed-variance fallback, applied identically in both uncertainty experiments.

For hidden reconstructed columns, control minimizes the sum of absolute errors divided by the number of scored entries in the full optimizer batch. Both uncertainty experiments retain this MAE contribution for non-XP columns. The diagonal experiment uses torchregress `NoisyTargetGaussianNLL` with `v_i=0.1+sigma_i**2`, contributing `0.5*(log(v_i)+r_i**2/v_i+log(2*pi))` per hidden XP coefficient. Variance0.1 is fixed in network units; it is not learned.

The full-covariance experiment uses torchregress `MultivariateGaussianLoss` separately for BP and RP, with `V=diag(sigma)*R*diag(sigma)+0.1*I`. Each band's hidden, finite subset S contributes `0.5*(r_S.T@inv(V_SS)@r_S+logdet(V_SS)+len(S)*log(2*pi))`. Visible or unavailable coefficients do not enter the scored covariance submatrix. Both band contributions and non-XP MAE use the same global scored-entry denominator as the control. No additional XP weighting, noise sampling, propagated G uncertainty or BP/RP cross covariance is introduced. Float64 covariance factorization rejects non-positive-definite matrices rather than silently repairing them.

Full covariance is cached sequentially on scratch, then indexed with exactly the same training row permutations. It requires about106.9GB of scratch for9M correlations, plus feature caches and environment. Final outputs, manifests, ordinary per-column MAE, all reconstructed-column MAE, XP-only MAE, spectra and reloadable checkpoints remain on ARC. Spectral diagnostics are evaluated under the shared validation masks.

Checks: diagonal identity-correlation equivalence, microbatch gradient equivalence, masked analytic correlated-Gaussian reference, error normalization before RobustScaling, and existing experiment tests.
