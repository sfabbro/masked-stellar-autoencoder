# VIR head integration for the frozen epoch72 screen

`VIRPredictionHead` in `training/prediction_vir.py` appends a 256-to-128 probabilistic latent map (64 means +64 variances) and64-to-3 NIG head. Modes `unweighted_nig`, `density_nig`, `vir` share initialization, latent architecture and raw-Gaussian per-coordinate-mean KL1e-3. NIG output is zero initialized, giving identical standardized initial mean0. The variance is nonzero and mode-dependent, so do not assert initial variance equality.

The caller owns the frozen encoder, exact row/label schedule, optimizer, RNG and resume. Never call standalone VIRRegressor.fit. Build with ONLY standardized fit labels, seed before construction, move to the selected device. `objective(latents, labels)` is scalar supervised loss; step its parameters using the common head optimizer. No heldout labels enter initialization, bin/density fit or statistics.

For fullVIR, the first head epoch has no recolouring. At the start of every subsequent head epoch call `refresh_statistics(all_fit_latents, fit_labels)`; latents are encoder eval-mode outputs, fit-only. Baseline/density modes may refresh to preserve exact I/O overhead but never recolour. Fixed n_bins20/kernel_sigma1.0/count-shrinkage5.0 implement the current library defaults; record them and fit-bin counts. For the frozen screen latents stay fixed but the learned latent-head statistics must still refresh as the head evolves.

`forward(latents)` returns `[N,1,2]`: standardized predictive mean and log Student-t total variance. This is NOT a Gaussian head. Use `posterior(latents)` to save gamma/nu/alpha/beta and score the exact Student-t distribution (df2alpha, scale sqrt(beta*(1+nu)/(alpha*nu))). Report native-label rather than physical-truth calibration. Inference uses predicted gamma to choose bins/density, no test-label argument exists. FullVIR uses one two-pass refinement matching library default n_refine1.

Checkpoint `state_dict()` includes both linear heads, fitted loss density/edges and all latent bin sufficient statistics/ready flag. Reconstruct with exact arm constructor and original fit labels before strict load. Save optimizer and RNG in the runner separately. Unit tests verify zero means, finite gradients, exact reload, row-permutation equivariance and KL convention. Mode/config are not inferred from weights: retain them in manifest and validate on reload.

Dependencies: torchregress f9f71f2 supplies public VIRLoss/VIRRegressor, including private static statistic/recolour helpers used by this adapter. Pin that immutable library version before production; no changes were made to source/environment pins by the adapter task. Focused tests ran using the torchregress repo's actual Pixi environment, not the old MSA66d52fe production pin.
