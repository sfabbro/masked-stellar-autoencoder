# Parallel XP reconstruction experiments from epoch47

Five matched continuations start from immutable `msa_pretrain_checkpoint_47.pth`, leaving main pretraining unchanged. All use the verified single-file 10M-star benchmark (9M train, 1M validation), 20M training presentations, seed42, optimizer batch32768 and microbatch512. Benchmark scaler arrays must exactly match the parent checkpoint. Validation masks/data, training row permutations, initial weights and dropout seeds are shared.

- `unchanged_control`: ordinary masked coefficient/other-column MAE, inherited AdamW state and learning rate.
- `corrected_signal_weighted_mae`: same MAE, multiplying each XP coefficient by training-derived reliability `clip(1 - median(sigma**2)/var(target), 0.05, 1)`. Weights use100K deterministic training rows, corrected G-normalized and RobustScaled errors; no validation data enter their estimation. Other columns have unit weight.
- `spectral_auxiliary_mae`: ordinary MAE plus a spectral term with weight0.1. Per star, project only hidden coefficient residuals through the calibrated GaiaXPy merged BP/RP basis, including RobustScaler scales but no center in the residual. Integrate absolute spectral error over wavelength and divide by the integral of the absolute observed spectrum. Multiply this relative error by the star's scored XP coefficient count; divide the auxiliary sum by the same full-optimizer-batch scored-entry count as MAE. Full finite observed XP is required for the auxiliary reference. Visible-coefficient prediction errors do not contribute.
- `adam_reset_mae`: ordinary MAE; clear AdamW moments and step counters while retaining inherited parameter-group settings and learning rate.
- `adam_reset_lr2_mae`: same reset, with inherited learning rates multiplied by2. Learning rates remain fixed throughout the bounded continuation, separating the reset comparison from the added LR change.

Compare completed runs by ordinary per-column, aggregate and XP-only MAE; additionally aggregate orders1–10,11–30 and31–55 separately for each band and together, using scored-entry counts. Report spectral mean/median integrated absolute fraction on the identical diagnostic sample. Verify parent checksum, benchmark identity, validation ID, masks, row budgets, optimizer steps and checkpoint reload probes. Optimizer differences are deliberate and documented per run in `optimizer_policy.json`; these fields should not be required to match across the reset experiments.

This is one seed and one spectral weight/LR factor. Objective changes retain inherited optimizer state so their initial comparison isolates the objective. Reset experiments keep the objective unchanged. A later combination of a successful objective and a successful optimizer policy requires another matched experiment.
