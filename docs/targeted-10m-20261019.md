# Targeted MSA regression programme, 19 October 2026

This is a bounded GPU screen on the existing audited benchmark and native label cohort. No new survey acquisition. Each adaptation arm receives exactly 10 million reconstruction-row presentations (9 million ordered TRAIN rows plus the first million repeated), 306 optimizer updates and 754,688 supervised label presentations including warmup. These are repeated presentations, not ten million labelled stars. There are 19,859 native fits and 100,620 reused identity-test stars, including 185 measured below −2 dex. Test results already informed method development; they are discovery diagnostics, not a new untouched benchmark.

The point-head programme tests residual Huber controls/seeds42/43/44, matched MSE and MSE+RankSim seeds43/44, Huber+RankSim, source-audited XP noise and masking, reconstruction weight0.03, quarter model learning rate, frozen encoder, and preserved pretraining parents85/86 versus72. Seeds change head initialization, label sampling, reconstruction masks and dropout; objective comparisons within a seed retain identical streams. The frozen-encoder arm still updates the decoder through reconstruction. Parent comparisons retain their own actual Adam moments, so they compare complete parent states rather than isolated encoder weights.

Augmentation modifies only visible supervised XP coefficients. Quoted raw XP errors are G-normalized and parent-scaled after actual mounted-source audits. Extra diagonal noise omits XP off-diagonal covariance and common G uncertainty, and is a robustness intervention, not an attenuation correction. Missing inputs remain missing; no label, reconstruction target or primary test input is perturbed. Augmentation uses a separate random generator.

Conditional observed-label flow heads model p(measured FeH | encoder representation), a different direction from the older p(summary | FeH) inversion. Affine scalar MAF is a conditional Gaussian control; bounded NSF8/16 provide flexible distributions. Training-only support bounds, deterministic point summaries, density normalization, exact likelihood/Jacobian tests, convergence and strict reloads must pass before submission. These heads do not deconvolve physical label truth. Flow moments must not be scored as Gaussian densities.

A separate test-time screen uses the already verified residual-Huber checkpoint. It compares unmodified inference, fixed masked/noisy view averaging, latent reconstruction refinement with frozen decoder/head, and per-object LayerNorm adaptation. Budgets and per-object resets are fixed in advance; observed FeH labels never determine adaptation or stopping. It is inference work, not another 10M training run.

All jobs need published immutable source and actual-input smoke/reload checks. Production additionally requires the original matched128XP unit gate and error-source audits where used. Accepted session IDs and distinct outputs are authoritative in the launch ledger. Completed paired inputs, predictions, snapshots, reconstruction arrays and full checkpoints must be preserved. Independent CPU/model/objective/source checks and paired reports with visual QA precede scientific ranking. Three-seed ensembles use source-aligned means and report member spread as uncalibrated; correlated models are not independent physical-error draws.

The completed270M continuation is preserved and needs a continuation-aware final CPU replay. No old verification or stopped original pretraining job is restarted. Later large training choices depend on current comparisons, reconstruction retention and the explicitly unresolved input/label-systematics policy.
