- Residual MSE control: required comparator for the corrected-score squared-error objective. Existing verified residual Huber remains the comparator for group DRO.
- Corrected-score EIV: subtracts the model's input-Jacobian noise variance using the new library loss. Per-star XP errors are G-flux normalized and parent-scaled, with production original-source audit required before fitting. Covariance is passed explicitly as [batch, feature, feature] diagonal variance, avoiding ambiguous square [batch, feature] standard-deviation matrices. Non-XP errors are set to zero for this XP-only intervention. Off-diagonal XP covariance and common G uncertainty are omitted; the nonlinear correction is a first-order approximation. No physical error floor or nonnegative-loss clipping. Supervised evaluation mode disables dropout during Jacobian differentiation; reconstruction retains its existing training policy. Finite-loss and gradient checks remain required.

This is likelihood-ratio estimation, not the distinct contrastive density-shaping paper, a calibrated physical posterior or a frequentist confidence interval.
